# Job Tracker
Express + Postgres (Neon). Deploys to Vercel with zero config: `src/index.js` is the app, `public/` is the UI.
Env vars: DATABASE_URL (Neon, auto-added by Vercel), SESSION_SECRET, ALLOWED_EMAILS, optional LLM_PROVIDERS + GEMINI_API_KEY.
Local: copy .env.example to .env, `npm install`, `npm start`.
